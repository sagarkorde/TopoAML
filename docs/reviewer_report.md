# Critical self-review from three perspectives

This is an agent self-review organized by the requested reviewer roles. It is not independent peer review.

## Mathematical topology

- Graph and flag homology are distinguished; beta1's dependence on V/E/C is explicitly checked.
- Filled and hollow tetrahedra validate H2 in supported complexes. The empirical pipeline extracts H0/H1 only.
- Maximum edge/vertex filtrations ensure nestedness. Essential bars remain infinite and are reported separately.
- Rips persistence is undirected and does not retain transfer direction. No novel homology invariant, PH/GAT invention or cycle-to-laundering conclusion is claimed.
- Residual concern: fixed Gaussian feature grids are basic vectorizations, not a novel learnable topological layer. Bounds and integer distances may cause ties/degenerate diagrams.

## Bitcoin AML

- Elliptic/Elliptic++ overlap is not treated as independent replication. Unknown nodes stay unknown.
- Elliptic2 suspicious subgraph labels have different units and meanings from transaction illicit labels.
- The release's same-step edges allow a coarse step-close evaluation, not a transaction-time early-warning claim. Historical label availability is not known.
- Exact raw-field observability is assumed at transaction record availability, not independently timestamped. Opaque aggregate fields are excluded.
- Residual concern: external-task structural baselines do not reproduce GLASS, GNNSeg or Sub2vec using the full background graph. Modern specialized AML architectures need additional matched reproductions.

## Machine learning and statistics

- Splits are frozen, preprocessing is train-fitted, checkpoints/thresholds use validation only, and five fixed seeds are retained.
- Primary paired bootstrap preserves step-level clustering. Seed standard deviations and test-population intervals must be labeled separately.
- Model configurations are fixed and within-family budgets equal; gating and concatenation have different parameter counts. Do not claim exact capacity matching.
- Residual concern: only ten test steps, narrow graph-construction choices for prediction, no nested hyperparameter search, no guaranteed optimal baseline, and no independent environment reproduction yet.
- Negative/inconclusive primary findings must remain visible in the abstract, results and conclusion.
