## Supported finding

The primary comparison of five-seed XGBoost ensembles, X+S+P minus X+S, changes average precision by approximately 0.000315, with temporal-block 95% interval approximately [-0.004063, 0.007247]. This is inconclusive. It does not demonstrate incremental utility or equivalence. Static Betti counts are deterministically redundant with structural controls. Separate Elliptic2 structural/persistent baselines also have intervals spanning zero. Full precision is in saved JSON outputs.
